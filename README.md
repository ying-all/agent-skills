# agent-skills

给 AI 用的技能包集合。每个目录一个技能，互相独立，按需取用。

| 技能 | 作用 |
|---|---|
| [deepdoc](deepdoc/) | 给一个主题，生成可离线阅读的交互式 HTML 文档（目录 / 搜索 / 深色模式 / 代码高亮） |

## 怎么用

每个技能目录里都有 `SKILL.md`（给 AI 的指令）和 `README.md`（给人的说明）。

- **让 AI 用**：把 `SKILL.md` 贴给它，或者说「读 <路径>/SKILL.md，按里面流程做」
- **自己跑**：看对应目录的 `README.md`

## 新增技能

新建一个目录，放 `SKILL.md` 和 `README.md`，再到本文件表格里加一行。
